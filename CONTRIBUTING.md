# Contribuer à TrouveMoi

Merci de votre intérêt pour le projet !

## Proposer une contribution

1. Consultez les issues existantes ou ouvrez-en une pour discuter d’un changement important.
2. Forkez le dépôt et créez une branche descriptive.
3. Faites une modification ciblée et mettez à jour la documentation si nécessaire.
4. Testez votre changement et indiquez les vérifications effectuées.
5. Ouvrez une pull request en expliquant le problème et votre solution.

## Bonnes pratiques

- Ne publiez pas de mot de passe, de clé secrète ou de fichier .env.
- N’utilisez pas de vraies données personnelles dans les issues ou les captures d’écran.
- Documentez les nouvelles variables de configuration.
- Pour un problème de sécurité, consultez SECURITY.md au lieu de publier les détails dans une issue publique.
