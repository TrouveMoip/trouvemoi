# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne pas publier les détails d’une vulnérabilité non corrigée dans une issue publique.

Utilisez le signalement privé de vulnérabilité de GitHub s’il est activé pour ce dépôt. Sinon, contactez le propriétaire du dépôt en privé via GitHub.

Décrivez le problème de façon responsable. N’accédez pas aux données d’autres personnes et ne les modifiez pas.

## Réponse

Les mainteneurs examineront le signalement et coordonneront une correction si nécessaire. Aucun délai de réponse n’est garanti pour le moment.
